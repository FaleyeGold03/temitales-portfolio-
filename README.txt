TEMITALES CREATIVE HUB PORTFOLIO

This is a static, responsive portfolio website. Open index.html in a browser to preview it.

PUBLISH WITH GITHUB PAGES
1. Sign in to https://github.com/FaleyeGold03
2. Create a new PUBLIC repository named: temitales-portfolio
3. Extract this ZIP on your computer.
4. Upload the index.html file and the complete assets folder to the repository root (not inside another folder).
5. In the repository, open Settings > Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Select branch main and folder /(root), then Save.
8. Wait for GitHub Pages to publish. The portfolio address should be:
   https://faleyegold03.github.io/temitales-portfolio/

Note: The address only becomes live after you create the repository, upload the files, and enable Pages. Do not share it as a live website until it opens successfully.
